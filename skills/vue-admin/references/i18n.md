# 菜单国际化

## 关联机制

路由 `meta.title` 的值作为 i18n key，在语言包的 `route` 命名空间下查找翻译。找不到则原样显示。

```typescript
// lang/utils.ts
export function translateRouteTitle(title: string): string {
  const key = `route.${title}`;
  return i18n.global.te(key) ? i18n.global.t(key) : title;
}
```

## 配置步骤

1. 在 `src/lang/package/zh-cn.json` 和 `en.json` 的 `route` 下添加 key：

```json
{
  "route": {
    "dashboard": "首页",
    "user": "用户管理",
    "role": "角色管理"
  }
}
```

2. 在菜单管理（后端动态菜单）或 `constantRoutes`（静态路由）中，`meta.title` 填写对应的 key（如 `"user"`）。

3. 系统自动在侧边栏、标签栏、面包屑中显示翻译后的标题。

## 语言切换

`appStore.changeLanguage(val)` 更新 `appStore.language`，i18n 和 Element Plus locale 自动切换。

## 在模板和脚本中使用

```vue
<!-- 模板 -->
<template>
  <div>{{ $t('navbar.search') }}</div>
</template>

<!-- 脚本 -->
<script setup lang="ts">
import { useI18n } from "vue-i18n";
const { t } = useI18n();
const title = t("login.username");
</script>
```

## 语言包结构

```json
{
  "route": { "dashboard": "首页", "document": "项目文档" },
  "login": { "username": "用户名", "password": "密码" },
  "navbar": { "search": "搜索", "theme": "主题" },
  "settings": { ... }
}
```
