# 质量检查

## 关键行为

| 范围 | 要求 |
| --- | --- |
| Wot v2 表单 | `wd-form` + `wd-form-item` + schema；required 星号不代替验证 |
| 提交 | 异步验证开始即防重入，失败保留草稿 |
| 分页 | 成功才推进页码，失败重试不跳页，新查询使旧响应失效 |
| 列表状态 | 区分首次加载、空数据、失败、刷新和加载更多 |
| 会话 | 单一响应式来源；登录、退出、401 同步内存与持久化，退出导航只有一个责任方 |
| 权限 | 入口与实际操作一致；服务端最终授权 |
| 敏感输入 | 密码不擅自 trim；密码、验证码、临时票据不记录或长期存储 |
| 资源 | 清理监听、计时器，取消或忽略过期异步结果 |

依据：[Wot v2 表单](https://v2.wot-ui.cn/component/form.html)；其他版本按其文档核对。

## 缓存与持久化

- 区分认证、偏好、可重建缓存；清缓存的统计与删除范围一致，不删除认证和偏好。
- 存储键集中定义，新键带应用和业务域前缀；只改常量标识符不改变实际 key 值。
- 已发布 key 或数据结构变更须迁移：兼容读取旧值，成功写入新值后再清理旧键，不覆盖有效新值、不清空全部存储。
- 迁移核对读取、写入、清理和恢复路径。

## 工程与验收

- 沿用包管理器、锁文件和兼容的依赖组合；声明生成规则见[页面与布局](pages-layout.md)。
- 格式及可自动检查规则交给现有 ESLint、Stylelint、Prettier；业务含义、注释必要性和样式归属人工评审。
- 可用规则包括 `vue/require-explicit-emits`、`vue/custom-event-name-casing`、`@typescript-eslint/consistent-type-imports`，按安装版本配置。

| 改动 | 验证重点 |
| --- | --- |
| 分页/会话 | 页边界、乱序、重试、失效和恢复 |
| 改名/存储迁移 | 导入、模板、自动注册、路由；旧数据迁移与清理范围 |
| 页面/样式 | 目标平台、小屏、长文本、大字体、键盘、安全区、浅深主题 |
| 生成配置 | 私有组件排除、路由唯一、分包及干净环境下的声明生成 |
| 性能 | 实测包体积和加载耗时后再选择优化 |
| 仅规范文档 | 结构、链接与规则一致性，不运行应用构建 |

测试针对实际风险；报告区分已验证、源码推断与未验证项。

工具依据：[eslint-plugin-vue](https://eslint.vuejs.org/rules/custom-event-name-casing.html)。
