# 注释

默认使用简洁中文，技术标识保留原文。注释补充代码无法直接表达的信息；先改善命名，不靠注释解释含糊名称。

## 何时需要

| 场景 | 必须说明的信息 |
| --- | --- |
| 业务限制、特殊分支、非显然取舍 | 原因、触发条件和边界 |
| 共享 API、Store action、组合函数、组件 props/emits | 名称与类型未表达的单位、前置条件、副作用或失败行为 |
| 平台兼容、临时绕过 | 适用平台/版本、依据、移除条件 |
| 字段、枚举、协议映射 | 不能从命名直接判断的业务含义或服务端约定 |

名称和类型已表达完整的简单函数、赋值、模板节点不补重复说明；不要求每个方法、ref 或文件都写注释。

## 写法

注释形式按「是否对外暴露」选择，不按重要程度选择：`/** */`（JSDoc）有工具链语义（IDE 悬浮提示、文档生成），只写在会被外部消费的成员上；组件内部私有实现用单行 `//`，避免文档注释泛滥稀释公开 API。

| 成员 | 注释形式 |
| --- | --- |
| 对外暴露：`defineProps` / `defineEmits` / `defineExpose`、`export` 的函数 / 类型 / 常量、Store 对外暴露的 state / getter / action | `/** */` |
| 组件内部：`computed`、`ref`、私有函数、局部变量、页面与组件 `<script setup>` 内部成员 | `//` |

```ts
// 正确：props（对外暴露）用 JSDoc
interface Props {
  /** 契约 images：图片数组，数组顺序即展示顺序，首图即默认封面 */
  images: ProductImage[];
}

// 正确：内部 computed 用单行注释
// 是否可提交：选齐 + 可售 + 库存已知且足量 + 数量合法
const canConfirm = computed(() => ...);

// 错误：私有成员写 JSDoc，公开 API 的文档提示被稀释
/** 是否可提交：选齐 + 可售 + 库存已知且足量 + 数量合法 */
const canConfirm = computed(() => ...);
```

- TS 声明文档用 `/** ... */`，放在声明前：符号级（对外函数、接口、类型、Store action、props）用标准多行格式（`/**` 首行、` * 内容`、` */` 尾行），字段级用单行 `/** 说明 */` 置于上方。实现原因用相邻的 `//`。模板用 `<!-- ... -->`，样式用 `/* ... */`。
- 文档先写一句用途或约束；只有存在额外信息时才加 `@param name - 说明`、`@returns`、`@throws`，不重复 TS 类型或编造错误行为。
- `TODO` 表示待完成事项，`FIXME` 表示已知缺陷；写明具体事项与完成条件，有现成 issue 时附真实链接。
- 检查规则抑制注释限定最小作用域，说明原因；临时处理补移除条件。

格式依据：[TSDoc @param](https://tsdoc.org/pages/tags/param/)、[Google TypeScript 注释建议](https://google.github.io/styleguide/tsguide.html#comments)。中文及适用范围为本项目约定。

## 清理与维护

- 修改行为时同步更新相关注释；删除过期说明和已完成 TODO，不保留大段注释掉的旧代码。
- 不添加装饰性分隔线、逐行翻译代码、空洞的“处理数据/初始化”说明或重复文件名的头注释。
- 不维护逐文件 `@author`、`@since`、日期、变更流水；历史交给版本控制，许可证和生成器要求的头注释保留。

## uni-app 编译指令

`#ifdef/#ifndef/#endif` 是编译指令，不按普通注释清理。保持平台标识、配对及编译前后语法有效；脚本使用行注释，模板使用 HTML 注释，样式（含 SCSS）使用块注释。

依据：[uni-app 条件编译](https://uniapp.dcloud.net.cn/tutorial/platform.html#preprocessor)。
