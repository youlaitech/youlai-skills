# 内容分发与数据迭代

## 内容复用：一鱼多吃

一篇深度内容可以拆成多个版本，适配不同平台的读者偏好，而不是简单复制粘贴。

### 一鱼三吃

| 版本 | 平台 | 标题风格 | 内容侧重 | 字数 |
|------|------|----------|----------|------|
| **实战版** | CSDN | 量化型（"3 分钟跑通""彻底搞懂"） | 步骤 + 代码 + 命令行截图 | 3000-5000 |
| **认知版** | 公众号 | 认知型（"为什么 99%""9 套共享"） | 架构图 + 观点 + 量化收益 | 2000-3000 |
| **深度版** | 掘金 / 知乎 | 深度型（"源码解析""架构设计"） | 源码 + 设计权衡 + 流程图 | 4000-6000 |

### 平台差异化要点

| 要素 | CSDN | 公众号 | 掘金 |
|------|------|--------|------|
| 代码块 | 多，指定语言高亮 | 超 15 行考虑截图（手机屏） | 可放完整源码链接 |
| Mermaid | 原生支持 | 需渲染成图片再贴 | 原生支持 |
| 段落 | 3-4 句 | 2-3 句（手机屏一行字少） | 3-4 句 |
| 结尾 | "收藏防走丢" + 技术栈表 | 引导关注 + 二维码 | 技术讨论引导 |
| 摘要 | 纯文本（不支持 Markdown） | 不需要摘要 | 支持摘要 |
| 标题 | ≤30 字 | 可稍长 | 可用 `｜` 分隔副标题 |

### 复用原则

- **核心素材只写一遍**：架构图、代码示例、对比表格是通用素材，三个版本共享
- **差异在包装**：标题、开头、结尾按平台调整，正文主体复用
- **不要简单搬运**：CSDN 发完直接贴公众号，读者一眼看出是搬运的，平台也不推。至少改标题和前 3 段

> 先写深度版（素材最全），再裁剪出实战版（取步骤和代码）和认知版（取观点和数据）。

## 文章长度与数据驱动迭代

### 推荐字数

文章不是越长越好。不同类型有不同的甜点区间：

| 文章类型 | 推荐字数 | 低于 | 高于 |
|---------|----------|------|------|
| 实战教程（快速上手） | 2000-3500 | 信息不够，跑不通 | 啰嗦，读者中途走 |
| 深度解析（架构/源码） | 4000-6000 | 浅尝辄止 | 读者收藏后不看（太长恐惧症） |
| 认知观点（选型/趋势） | 1500-2500 | 论据不足 | 稀释观点，失去力度 |
| 问题排查（踩坑/Debug） | 1000-2000 | 没说清楚 | 读者要的是答案不是故事 |

> 字数是参考不是硬指标。判断标准：删掉任何一段，读者会不会觉得缺了什么？如果不会，删。

### 发布后数据复盘

发布后 48 小时看数据，用数据指导下篇选题和写法。

| 指标 | 看什么 | 说明 |
|------|--------|------|
| **阅读量** | 标题和摘要的效果 | 阅读量低 → 标题不够吸引或选题太冷 |
| **完读率** | 正文质量 | 完读率低 → 中段有"文字墙"或内容拖沓 |
| **收藏率** | 实用价值 | 收藏率高但评论少 → 干货足但缺互动点 |
| **评论数** | 争议性和共鸣度 | 评论少 → 缺观点，读者没有"想说点什么"的冲动 |
| **转发数** | 社交货币 | 转发少 → 文章没有可转发的谈资或观点 |

### 高转化段落模式

复盘时标记文章中"收藏/转发发生时读者所处的位置"——大部分互动发生在特定段落。常见的高转化段落：

- **对比表格**：读者收藏后当参考用
- **检查清单**：读者收藏后当工具用
- **"恍然大悟"段落**：读者转发时引用的观点
- **踩坑总结**：读者收藏后防踩坑

> 把高转化段落提炼成模式，下一篇复用。低转化段落（纯描述性文字、通用背景介绍）下次压缩或删除。

## 发布检查清单

发布前逐项检查：

**选题与传播**

- [ ] **选题验证**：有人在搜、读者能用、有独特视角
- [ ] **情绪触发**：至少触发一个情绪（共鸣/意外/焦虑/爽感）
- [ ] **社交货币**：有可转发的观点或可收藏的工具（表格/清单）
- [ ] **叙事弧**：问题→挣扎→顿悟→方案，四步完整
- [ ] **"恍然大悟"段落**：有至少 1 段打破常识认知的内容

**内容规范**

- [ ] **效果前置**：性能对比/升级 PK 图是否添加（适用时）
- [ ] **摘要**：纯文本、80-120 字、无 Markdown
- [ ] **前言**：包含背景、看点、源码链接
- [ ] **标题**：SEO 友好、关键词明确、H2 含搜索词
- [ ] **章节层级**：不超过三级
- [ ] **段落**：每段不超过 3-4 句，一段一个要点
- [ ] **代码块**：指定语言、可独立运行
- [ ] **图表**：使用 Mermaid 语法
- [ ] **结语**：包含总结、扩展、共情式结尾
- [ ] **链接**：有效、标注来源
- [ ] **图片**：有 alt 文本或占位符
- [ ] **人味**：无 AI 排比/万能过渡/端水表达，通读像在跟同事聊天

**平台适配**

- [ ] **字数**：符合文章类型的甜点区间
- [ ] **平台版本**：按平台调整标题、开头、结尾、代码长度
- [ ] **时效性**：如蹭版本发布窗口，确认在 72 小时黄金期内
